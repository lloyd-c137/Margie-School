# Margie School

**一个完全免费、非营利的 AI-native 教育实验。**

Margie School 不只是要让学习更高效。我们要挑战一种更深的假设：一个人必须先沿着既定教育路径学习十几年、通过考试、取得文凭，才有资格探索自己热爱的领域、开启事业或为社会创造价值。

**学习、探索、实践和创造不应该被人为切割成先后阶段。**

我们希望打破传统教育路径对学习机会、能力认证和社会认可的过度控制，让人可以自主决定学什么、为什么学、何时开始行动，并以真实能力而不是单一学历标签获得理解和机会。

> 我们不是要建立另一套替人决定未来的教育体系。我们要让每个人重新拥有决定如何学习、何时开始、走向何处的权利。

## 使命与边界

- **学习自主**：学习者决定学习的方向与人生目标，Margie 不替他们制定成功标准。
- **真正掌握**：AI 做出作品不等于学生学会了。我们重视解释、应用、调试和迁移能力。
- **学习与行动并行**：不必等获得文凭才开始探索、研究、创作、协作或创业。
- **反对单一评价权威**：支持通过可验证的能力、成果与真实反馈获得社会信任。
- **教育可及性**：项目完全免费、非营利，努力降低财富、地域和背景造成的学习机会差异。
- **反强制，不反严谨**：反对强制统一路径与无意义的门槛，但尊重系统知识、优秀教师、严格验证及必要的职业安全标准。

我们**不是**反知识、反教师、反大学或反所有考试。我们也**不**要求所有学习者创业、就业或变现。一个人可以因为纯粹的好奇心而学习。

## 当前阶段

**理念与实验设计阶段。** 项目正式名称为 Margie School；完全免费、非营利、AI-native 的原则已明确。首个探索方向为 **Vibe Coding**，曾提出以约 10 名零基础学习者验证「能够构建并真正理解、修改作品」的目标。

第一节课主题已确定为 **我们一直在等你（We've Been Waiting for You.）**：教育哲学启蒙，而非直接开始编程。课程须完全在线、手机端可完整参与；明确偏好 Brilliant 式交互学习。Playable Curriculum 为教学模式候选，具体课程形式、试讲安排仍待确认。

课程、产品架构、技术底座、实际参与人数、学习成效和长期可持续性**均尚未在本仓库得到实证确认**。研究与实施记录应明确区分「目标」「假设」「实验数据」和「已验证结论」。

名称受到 Isaac Asimov 的短篇小说 *The Fun They Had* 启发。我们希望技术帮助人学习，而不是成为另一种支配人的机械教育体系。
