# Margie School · 当前讨论状态与卡点

> 2026-11-28 · Decision log / Open questions
> 本文件汇总当前讨论，优先级和建议行动为整理时提出的工作方案，并非已确认的交付承诺。未进行用户招募、试讲或产品开发验证。

## 一、已经确定

- 正式项目名 Margie School，完全免费、非营利、AI-native。
- 长期使命：打破传统教育路径对教育、社会评价及机会话语权的过度集中；学习、探索、实践与创造可以并行。
- 尊重学习者自主权，真正掌握知识优先于 AI 代劳成果；不将就业、创业和变现强加为共同目标。
- 首个学习方向 Vibe Coding；第一节课不直接 Build，而是先进行教育哲学启蒙。
- 第一节课正式主题：**我们一直在等你**（We've Been Waiting for You.）。
- 第一课内容：质疑教育本质，探讨学习方式、传统教育体系与评价体系；重点关注好奇心、创造力和判断力。
- 教学必须纯线上，手机端必须能完整参与全部核心学习任务，不依赖线下、电脑或物理键盘。
- 明确偏好 Brilliant 式交互教学：知识可操作、可探索、可验证；具体教学机制与产品形态仍待确认。
- Slogan 讨论暂停，未确定正式品牌 Slogan。

## 二、已讨论但尚未拍板

- 课程形式候选：Playable Curriculum（可玩的课程）、可操作知识模型、互动叙事、AI 模拟、Agent Replay、教学对话与自由创造；参见 [教学交互方案](curriculum/VIBE_CODING_TEACHING.md)。
- 历史试讲候选参数：6–10 人，90 分钟，七幕式流程；须重新评估在线手机体验的时长、分段与同步/异步方式。
- 交付载体：纯线上已确定；移动网页、原生应用、异步自助及可选真人在线引导仍待选定。原线下候选不再适用。
- 开场欢迎语、匿名互动、学校重设计活动、Question Margie、私人反思等为候选活动。
- 形成性评价：关注问题意识、理由、反例、替代方案和观点修正，不计分、不排名、不以立场认同为目标。
- AI Tutor 和 Coding Agent 的分工、在线 IDE 及其他基础设施属于前期产品设计方向；无最终技术选型。

## 四、建议的下一步（尚未确认）

1. 明确首场课的纯线上手机形式、目标学习者与最短可行时长，冻结首版范围。
2. 完成低技术依赖的手机端在线教学原型：一个思想实验、一个技术交互实验、问题链、真实/模拟材料区分、反馈和反思；不先开发完整平台。
3. 走查并删减：确保每个活动服务教育目标；必须给不同立场、安静思考和反方论证留时间。
4. 进行小规模试讲（人数和日期待确认），在获得必要同意后收集最少的证据。
5. 复盘手机操作、理解、迁移与引导负担，再决定专门平台、AI 和运行环境的范围。

## 五、非目标与当前证据

暂不确定 Slogan；不需要先完成完整 LMS、AI IDE 或影片才能试讲；不要求学生首课生成代码或产品；不将学生反对传统学校的比例作为 KPI。

仓库目前以使命、原则、实验设计与首课方案文档为主。纯线上及手机端完整参与已确定，具体互动形式尚待确认，没有已核实的首场试讲、学生参与数据、学习成效、产品上线或技术选型证据。以真实实验更新本文件，不把愿景倒写为成果。
